# CIFNEW投稿创作公约

「CIFNEW」是一个由大家共同创建的内容社区，致力于降低职业风险与减少不确定性。社区鼓励大家认真创作和诚恳交流，共建共享，收获成长。 为了能让所有用户享有开放、友善和有收获感的社区，我们希望以下能成为社区的共识：


## 一、CIFNEW应用功能说明

1. 发展现状及趋势

当前的求职流程虽然已经形成了以校园招聘、网络招聘和社会招聘为主的相对完整的就业体系，但在实际执行过程中仍然存在一些可优化的部分：

一方面是招聘信息分散且不对称。招聘信息分布在学校就业网站、企业官网及各类招聘平台，学生难以全面、及时地获取真实有效的岗位信息，部分招聘信息还存在描述不准确、岗位要求与实际工作内容不符等情况，甚至存在虚假岗位、招聘诈骗等风险；普通求职流程通常包括求职准备、获取招聘信息、投递简历、简历筛选、笔试测评、面试、录用通知、签订就业协议以及正式入职等环节，求职流程主要围绕招聘与录用展开，系统缺乏有效的反馈回路，就业决策缺乏有效支持；

另一方面是求职者的意识缺乏。求职者对行业发展、企业实际情况、岗位薪资待遇、职业发展空间及劳动合同等信息了解不足，容易出现职业定位不清晰、盲目投递和就业选择困难等问题；对地方人才政策及相关公共服务政策的了解也相对不足，求职者可能不了解不同城市提供的人才补贴、人才绿卡、人才公寓、公租房、住房补贴、落户政策、就业创业扶持及社保补贴等政策，也不清楚相关政策的申请条件、办理流程、有效期限和适用范围。

因此，需要更加专业和透明的信息通路改善求职体验，提高招聘效率和人才匹配质量，减少求职者的职业不确定性，增强求职者的职业稳定性。

2. 应用功能和使用说明

CIFNEW是非中心化的网络应用，由前端、后端和路由节点端三部分组成。路由节点端通过星际文件系统（英语：InterPlanetary File System，缩写英语：IPFS）为后端提供网络路由和数据传输。主要业务功能如下：

- 公司信息维护：公司信息列表、公司信息卡片发布、公司信息编辑、关联组织编辑、公司检索。
- 文章操作：文章编辑与发布、图像上传、文章删除、分类检索、本地存储、文章编辑器（MarkDown模式、OfferShow 模式、问答模式）。
- 问答界面：有关“出行、租房、校园、职场、入职、离职、消费、保险、其他”的提问与回答、社保计算器。
- 用户信息维护：信息填写、修改、导出、保存、加载。


## 二、CIFNEW投稿使用规范


- 禁止发布涉及政治的内容。正确使用涉及到的特定名词称谓，请勿错用、滥用特定标识、呼号、称谓、用语、地图等。如果您在创作过程中涉及版图作为素材，您可以通过查询国家地理信息公共服务平台确认正确的国家版图及全国各省级节点版图。
- 禁止发布重要机密类内容。
- 禁止发布危险违禁物品的宣传、制作、销售、使用内容。
- 禁止发布宗教类内容。
- 禁止发布或营销封建迷信、不科学、超自然力量内容。
- 禁止发布其他法律、法规、规章、规范性文件禁止的内容。
- 禁止发布违背公序良俗的内容，自觉维护社区和谐氛围。
- 请不要填写与内容不相关或者无意义的标签内容。为了方便文章内容能被用户准确搜索，请填写与内容相关的标签，包括但不限于涉及的位置信息、公司简称、子公司名称、行业概念、文章本身的属性等。
- 如发布含有国内外时事、公共政策、社会事件等信息时，请在内容中注明相关信息的时间、地点或参考信源等。




## 声明

我们鼓励大家用认真的态度发布内容，基于真实的信息表达观点，杜绝捏造事实，不造谣传谣，不有意误导和歪曲。同时，请广大用户提高安全防范意识，仔细甄别网络信息及相关内容的真实性。
